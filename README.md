# Backroom Raycaster

Petit moteur de rendu 3D type *Wolfenstein 3D* basé sur du raycasting en C avec OpenGL / GLUT.

---

## Fonctionnalités

- Renderer 3D par raycasting
- Mini-map 2D
- Déplacement du joueur (WASD)
- Rotation de la caméra
- Détection de collisions avec les murs
- Rendu pseudo-3D temps réel

## Usage

- execute la commande "make" dans la racine du projet puis "make run"
